# XAI Decathlon: SHAP

AIPI 590.01 (Emerging Trends in Explainable AI), Duke, Fall 2026. Unit 2 in-class activity (online cohort).

One XAI method, **SHAP**, applied across the ten Decathlon events using the course's toy models:

- **Tabular risk model (random forest):** TreeSHAP, plus SHAP interaction values
- **Image shortcut model (CNN):** KernelSHAP over an 8×8 grid of image patches

The notebook contains the completed results table, per-event evidence and medals, the final model profile, and answers to the online-cohort questions.
